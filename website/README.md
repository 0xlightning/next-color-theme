# Website Workspace — Next Color Theme Dashboard

This directory contains the primary **Next.js 16 (App Router)** web application codebase.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start local development server (http://localhost:3000)
npm run dev

# Run linting check
npm run lint

# Build optimized production bundle
npm run build

# Start production server
npm run start
```

## 📦 Key Folder Locations

- `app/` – App Router routes (`/`, `/analytics`, `/login`, `/settings`) & root layout.
- `src/components/widgets/` – 20 standalone widgets with components, typed mock data, and barrel exports.
- `src/components/charts/` – Reusable charting primitives (`AreaChart`, `BarChart`, `DonutChart`, `LineChart`, `MiniBarChart`, `ProgressRing`, `Sparkline`).
- `src/components/ui/` – 60+ Shadcn UI primitive components.
- `src/components/layout/` – Application shell layouts (`DashboardLayout.tsx`, `Header.tsx`, `Sidebar.tsx`).
- `src/theme/` – Global CSS tokens & Tailwind CSS v4 styling rules.
